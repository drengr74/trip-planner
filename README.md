# Планировщик поездки

Веб-приложение на Streamlit и CrewAI: поиск города и составление плана поездки одного человека.

## Локальный запуск

Из корня проекта:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Настройки

Создайте файл `.env` в корне проекта. Нужны:

- `OPENAI_API_KEY` — ключ доступа к модели;
- `OPENAI_MODEL` — идентификатор модели в виде «вендор/модель»;
- `OSM_USER_AGENT` — название приложения и контакт (email или URL) для запросов к OpenStreetMap;
- `TAVILY_API_KEY` — необязательный ключ веб-резерва. Без него план по OpenStreetMap строится, а для неподтверждённого интереса будет сказано, что веб-поиск недоступен.

Не коммитьте `.env`: в нём секреты.

## Streamlit Community Cloud

Укажите главный файл `streamlit_app.py`. Секреты задайте в настройках приложения теми же именами, что и в `.env`. Файл с секретами в репозиторий не кладите.

## Ограничение

Цены и расписания в плане могут быть непроверенными. Сверьте их перед поездкой.
